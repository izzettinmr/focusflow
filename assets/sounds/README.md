# FocusFlow sounds

Original sounds synthesized for this project with `scripts/generate-sounds.py`.
No recordings, third-party samples or external sound downloads are used.

- `start.wav`: short, two-note rising bell, 0.85 seconds.
- `complete.wav`: three clear bell strikes, 2.7 seconds.
- Mono, 44.1 kHz, 16-bit PCM WAV; peak amplitude 0.82.

Both files are packaged for offline native playback. Settings control their volume.
